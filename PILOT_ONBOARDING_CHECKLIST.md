# Pilot Dealership Onboarding Checklist

**Program:** GrayArx Pilot Launch  
**Duration:** 4 Days per Dealership  
**Dealerships:** 5 (Staggered start)  

---

## Pre-Onboarding (1 week before)

### Dealership Selection & Confirmation
- [ ] Dealership confirmed as pilot participant
- [ ] Primary contact identified (owner/manager)
- [ ] Contact email & phone verified
- [ ] Dealership profile created in system
- [ ] Welcome email sent with onboarding schedule
- [ ] NDA/terms of service signed
- [ ] API key pre-generated and ready

### Internal Preparation
- [ ] Support team briefed on dealership profile
- [ ] Training materials prepared
- [ ] Demo data loaded into sandbox
- [ ] Monitoring dashboard configured for dealership
- [ ] Escalation contacts identified
- [ ] Knowledge base articles reviewed

---

## Day 1: Account Setup & Configuration

### Morning (9:00-12:00)

**Account Creation**
- [ ] Dealership account created in production
- [ ] Admin user account created
- [ ] Initial password set securely
- [ ] Two-factor authentication enabled
- [ ] API key provided to dealership
- [ ] Webhook URL configured

**System Access Verification**
- [ ] Dealership can log in to dashboard
- [ ] All navigation menus accessible
- [ ] User permissions verified
- [ ] Mobile access tested
- [ ] Browser compatibility confirmed

**Notification Setup**
- [ ] Email notification preferences configured
- [ ] Quiet hours set (default: 18:00-08:00)
- [ ] Timezone verified (default: Africa/Johannesburg)
- [ ] Notification frequency selected (immediate/daily/weekly)
- [ ] Test email sent and received
- [ ] Email delivery confirmed

### Afternoon (13:00-17:00)

**Initial Data Import**
- [ ] Historical leads CSV prepared
- [ ] CSV format validated
- [ ] Bulk import initiated
- [ ] Import progress monitored
- [ ] Error handling verified
- [ ] Data quality spot-checked
- [ ] Import completion confirmed

**Dealership Profile Completion**
- [ ] Company information updated
- [ ] Contact details verified
- [ ] Billing information configured
- [ ] Language preferences set
- [ ] Vehicle types configured
- [ ] Service area defined
- [ ] Branding customized (if applicable)

- [ ] Sample import performed
- [ ] Error handling demonstrated

- [ ] Import history reviewed
- [ ] Dealership performs test import
- [ ] Success criteria verified

## Success Criteria

**Onboarding is successful when:**

✅ Dealership can log in and access all features  
✅ All 5 features are working correctly  
✅ Dealership team is trained and confident  
✅ Initial data has been imported successfully  
✅ Monitoring is active and alerting properly  
✅ Support procedures are understood  
✅ Dealership satisfaction score ≥4/5  
✅ Go-live approval obtained
