## Dealership Selection Criteria

**Required Qualifications:**
- Active dealership with 50+ monthly leads
- Dedicated staff for training (minimum 2 people)
- Willingness to provide feedback
- Commitment to 4-week pilot period
- Signed pilot agreement

**Preferred Characteristics:**
- Geographic diversity (different SA provinces)
- Vehicle type diversity (new, used, luxury, economy)
- Different dealership sizes (small, medium, large)
- Existing CRM or lead management system
- Digital-savvy management team

## Confirmation Process

### Step 1: Initial Contact (Week 1)

**Email Template:**

```
Subject: Exclusive Pilot Opportunity - GrayArx AI Platform

Dear [Contact Name],

We're excited to invite [Dealership Name] to participate in an exclusive pilot program for GrayArx, the Dealership AI Operating System.

GrayArx helps dealerships:
- Capture and qualify leads automatically
- Score leads by quality (10-factor analysis)
- Track performance with real-time analytics
- Manage dealership operations efficiently
- Improve conversion rates by 15%+

We're looking for 5 forward-thinking dealerships to join our pilot program. Your dealership has been selected based on your reputation for innovation and customer focus.

**Pilot Program Details:**
- Duration: 4 weeks
- Onboarding: 4 days (comprehensive training)
- Support: 24/7 for critical issues
- Cost: FREE during pilot period
- Commitment: Feedback and usage data

**Next Steps:**
1. Review the attached pilot agreement
2. Schedule a 30-minute confirmation call
3. Sign the agreement and NDA
4. Begin 4-day onboarding

Would you be available for a call this week to discuss the opportunity?

Best regards,
[Your Name]
GrayArx Team
```

### Step 2: Pilot Agreement

**Key Points:**
- Pilot duration: 4 weeks
- Data usage: Feedback and metrics only
- Confidentiality: Standard NDA
- Support: 24/7 for critical issues
- Cost: FREE during pilot
- Post-pilot: Option to continue as paying customer

### Step 3: Confirmation Call

**Call Agenda (30 minutes):**
1. Introduction and platform overview (5 min)
2. Dealership needs and challenges (5 min)
3. How GrayArx addresses their needs (5 min)
4. Pilot program details and expectations (5 min)
5. Next steps and onboarding schedule (5 min)

**Call Checklist:**
- [ ] Confirm dealership interest
- [ ] Identify primary and secondary contacts
- [ ] Discuss current lead management process
- [ ] Understand key pain points
- [ ] Confirm onboarding dates
- [ ] Provide API documentation
- [ ] Send welcome package

### Step 4: System Setup

**For Each Confirmed Dealership:**
- [ ] Create dealership account in production
- [ ] Generate API key
- [ ] Create admin user account
- [ ] Send login credentials securely
- [ ] Configure notification preferences
- [ ] Set up monitoring dashboard
- [ ] Brief support team

## Pilot Agreement Template

**GRAYARX PILOT PROGRAM AGREEMENT**

**Effective Date:** [Date]  
**Pilot Duration:** 4 weeks  

**Parties:**
- GrayArx (Provider)
- [Dealership Name] (Participant)

**Terms:**

1. **Program Duration:** The pilot program runs for 4 weeks from the onboarding start date.

2. **Services:** GrayArx provides access to the following features:
   - Email Notification System
   - Advanced Audit Logging
   - Lead Quality Scoring
   - Performance Analytics
   - Bulk Lead Import

3. **Support:** GrayArx provides 24/7 support for critical issues and business hours support for standard issues.

4. **Cost:** The pilot program is FREE. No fees are charged during the 4-week pilot period.

5. **Data:** The dealership agrees to provide feedback and usage metrics to help improve the platform.

6. **Confidentiality:** Both parties agree to keep pilot details confidential per the attached NDA.

7. **Post-Pilot:** After the pilot, the dealership has the option to:
   - Continue as a paying customer
   - Provide feedback for improvements
   - Participate in future beta programs

8. **Termination:** Either party can terminate with 24 hours notice.

**Signatures:**

Dealership Representative: ___________________  Date: ___________________

GrayArx Representative: ___________________  Date: ___________________
