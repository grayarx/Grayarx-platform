# GrayArx demo inventory CSVs

Matched **make/model photos** from Wikimedia Commons (not random Unsplash cars).

| File | Cars | Use |
|------|------|-----|
| `grayarx-demo-mainstream-8photos.csv` | 8 SA mainstream (Hilux, Ranger, Polo, …) | Client demos |
| `grayarx-demo-premium-8photos.csv` | 6 premium (BMW, Merc, Audi, …) | Premium yard demos |
| `grayarx-demo-1000-cars-8photos.csv` | 1000 | Scale / stress test |

## Import on grayarx.com

1. Open **CSV Import**
2. Turn **Save photos to GrayArx** **OFF** (keeps Wikimedia links; avoids timeouts)
3. Upload or paste the CSV → **Preview** → **Import**
4. Same stock numbers (`STK-2001` …) **update** existing cars — re-import to fix wrong photos

Photos are free Wikimedia images of the correct model family. For a live dealership, replace with your own 8-angle yard photography.
