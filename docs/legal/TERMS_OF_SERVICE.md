## 2. Service Description

GrayArx is a cloud-based automotive dealership management and AI-powered sales platform that provides:

- **Inventory Management:** Vehicle listing, CSV import, and showroom display
- **Lead Capture & Management:** Automated lead collection, triage, and follow-up scheduling
- **AI Agents:** Autonomous software agents that draft communications (email, WhatsApp, voice) on behalf of the dealership
- **Analytics & Reporting:** Dashboard, agent activity feed, and performance metrics
- **Trade-In Valuation:** Automated trade-in estimates using the Tumi agent
- **Finance Calculator:** Buyer affordability assessment tool
- **Comparison Tool:** Multi-vehicle side-by-side comparison for buyers
