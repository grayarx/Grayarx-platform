# GrayArx Dealership OS strategy

GrayArx is designed as the **operating system to run the yard** — not a chatbot bolt-on and not a clone of Adas accounting.

## What “best” means

| Lane | Win condition | Status |
| --- | --- | --- |
| Sales | Nala answers from **live stock**, books viewings 24/7 | Live |
| Parts | Quote + hold from counter stock | Live |
| Service | Book workshop jobs + status path | Live |
| Trade-in | Intake → indicative band → appraiser | Live |
| Recovery | Marketplace + missed-call | Live / shipping to production channels |
| Proof | Monday ROI | Live |
| Group | Multi-branch + CRM webhooks | Roadmap (Enterprise) |

## What we will not build first

- Full VAT/SAPS/floorplan DMS (Adas already owns this cheaply at R1,260/mo)
- “Cancel AutoTrader” features
- In-house lender/e-sign OS (partner MotorX-class depth later)
