## Common Issues & Solutions

### Issue: CSV won't upload
**Solution:**
- Check file format (must be .csv)
- Check for special characters in headers
- Try downloading template and copying data
- Send them corrected file

### Issue: No leads coming in
**Solution:**
- Check if chatbot is active
- Check if website is live
- Check if WhatsApp is connected
- Suggest they test with a test message

### Issue: Leads not converting
**Solution:**
- Review lead quality score
- Check if dealership is responding quickly
- Suggest AI training with their data
- Review chatbot responses

### Issue: Dealership wants to cancel
**Solution:**
- Schedule urgent call
- Understand why (price? features? results?)
- Offer solutions (upgrade? discount? features?)
- If leaving: collect feedback for improvement
