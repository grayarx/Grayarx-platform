## Platform Overview

### What is GrayArx?

GrayArx is the Dealership AI Operating System designed to help South African dealerships capture, qualify, and convert leads more effectively. The platform combines artificial intelligence with dealership-specific workflows to improve sales performance.

### Core Features (Phase 33)

**1. Email Notification System**
- Dealerships receive email alerts for new leads, status changes, bookings, and pre-approvals
- Configurable quiet hours (e.g., don't send emails between 18:00-08:00)
- Per-notification-type toggles (enable/disable specific alert types)
- Notification history tracking

**2. Advanced Audit Logging**
- Every action in the system is logged (who did what, when, and why)
- Dealerships can view audit logs and export to CSV
- Helps with compliance (POPIA) and troubleshooting
- Statistics show activity patterns

**3. Lead Quality Scoring**
- Automatically scores each lead on a 0-100 scale
- 10-factor analysis: source, language, response time, engagement, vehicle type, price range, location, urgency, contact quality, history
- Helps dealerships prioritize high-quality leads
- Shows top strengths and weaknesses for each lead

**4. Performance Analytics**
- Daily KPI tracking: lead volume, conversion rate, booking rate, ROI, cost per lead
- Dealerships can view historical trends
- Compare performance across time periods
- Identify improvement opportunities

**5. Bulk Lead Import**
- Dealerships can import leads from CSV files
- Automatic validation and error detection
- Retry mechanism for failed imports
- Import history tracking

## Common Issues & Solutions

### Issue: Dealership Can't Log In

**Possible Causes:**
- Wrong credentials
- Account not activated
- Browser cache issue
- Two-factor authentication problem

**Solution Steps:**
1. Verify email address and password
2. Check account activation status
3. Clear browser cache and cookies
4. Try different browser
5. Reset password if needed
6. Escalate if still not working

---

### Issue: Email Notifications Not Received

**Possible Causes:**
- Notifications disabled in preferences
- Email in spam folder
- Quiet hours active
- Email service issue
- Invalid email address

**Solution Steps:**
1. Check notification preferences
2. Verify quiet hours setting
3. Check spam/junk folder
4. Ask dealership to check email settings
5. Test with new lead
6. Check email service status
7. Escalate if still not working

---

### Issue: Lead Quality Score Seems Wrong

**Possible Causes:**
- Lead data incomplete
- Scoring algorithm behavior
- Recent data update
- Calculation in progress

**Solution Steps:**
1. Review lead data completeness
2. Explain 10-factor scoring system
3. Show factor breakdown
4. Discuss expected vs actual score
5. Provide improvement recommendations
6. Escalate if score appears incorrect

---

### Issue: Bulk Import Failing

**Possible Causes:**
- CSV format incorrect
- Invalid email addresses
- Duplicate leads
- Missing required fields
- File too large

**Solution Steps:**
1. Review CSV format requirements
2. Check for required fields
3. Validate email addresses
4. Check for duplicates
5. Verify file size
6. Test with smaller sample
7. Use retry mechanism
8. Escalate if still failing

---

### Issue: Performance Metrics Not Updating

**Possible Causes:**
- Calculation not yet run
- Data not yet available
- System issue
- Timezone mismatch

**Solution Steps:**
1. Check last calculation timestamp
2. Verify data availability
3. Manually trigger calculation if needed
4. Check dealership timezone
5. Wait for next scheduled calculation
6. Check system logs
7. Escalate if still not updating

## Escalation Procedures

### When to Escalate

Escalate an issue when:
- You cannot resolve within response time
- Issue is beyond your expertise
- Issue affects multiple dealerships
- Issue is security-related
- Dealership requests escalation
- Issue is critical (P1)

### Escalation Path

**Level 1:** Support Team Member (Your Level)  
**Level 2:** Technical Lead  
**Level 3:** Engineering Team  
**Level 4:** Founder/CTO (for critical issues)  

### How to Escalate

1. Document the issue completely
2. Include all troubleshooting steps taken
3. Provide relevant logs and error messages
4. Identify impact and urgency
5. Contact escalation person directly
6. Provide dealership contact information
7. Follow up on resolution
